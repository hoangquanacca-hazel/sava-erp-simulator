# Agent config

## Issue tracker
Local files. Issue được lưu dưới dạng file markdown trong repo, không dùng GitHub Issues.
Vị trí: `docs/issues/` (mỗi issue một file `NNN-slug.md`, có trạng thái: open | in-progress | done).

## Nơi lưu tài liệu
`docs/`, cùng chỗ với `intent.md` và `spec.md`. Không tạo thư mục hay hệ tài liệu thứ hai.

## Ghi chú
- `intent.md` và `spec.md` hiện chưa có trong nhánh `feat/sim-p0-mfg`. Khi có, đặt tại `docs/intent.md` và `docs/spec.md`.
