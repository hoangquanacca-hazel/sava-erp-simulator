- Contract / adapter / config / rule versions:

- Rows raw/data/accepted/rejected/duplicate/emitted + totals by currency/UoM:
- Negative cases + command/log artifacts + hashes:
- Exceptions / owner / disposition / expiry:
- Lineage sample and report screenshots:
- Preparer identity / timestamp:
- Independent reviewer identity / timestamp / signed artifact hash:
- SME approval / release owner decision:
- Backup / restore / rollback evidence:
